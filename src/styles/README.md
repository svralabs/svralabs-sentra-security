# Style Guide Tokens

## Color Palette

### Primary Colors
- `primary`: #818CF8
- `on-primary`: #1E1B4B
- `primary-container`: #E0E7FF
- `on-primary-container`: #1E1B4B

### Surface Colors
- `surface-dim`: #121212
- `surface`: #1E1E1E
- `surface-container`: #2A2A2A
- `surface-container-lowest`: #1A1A1A

### On Surface Colors
- `on-surface`: #E0E0E0
- `on-surface-variant`: #C7C7C7

### Outline Colors
- `outline-variant`: #424242

## Typography Scale

### Font Families
- `headline-sm`: Roboto, sans-serif
- `headline-md`: Roboto, sans-serif
- `label-mono`: Roboto Mono, monospace

### Font Sizes
- `headline-sm`: 1.25rem
- `headline-md`: 1.5rem
- `label-mono`: 0.875rem

## Spacing Tokens

### Gutters and Margins
- `gutter`: 1.5rem
- `margin-desktop`: 2rem
- `section-gap`: 6rem

### Container Widths
- `container-max`: 1200px

## Shadows

### Rim Light
- `rim-light`: 0 1px 2px 0 rgba(255, 255, 255, 0.05)
